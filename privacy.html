This Privacy Policy explains how Invisibly collects, processes, stores, and protects personal data in compliance with the Digital Personal Data Protection (DPDP) Act, 2023 and the DPDP Rules, 2025 (together, "DPDP Act"). 2. Data Fiduciary and Contact Information Data Fiduciary: DeltaIQx LLP Grievance Officer: [Name] Email: grievance@deltaIQx.com Phone: [Number] 3. Data Collection and Processing 3.1 Types of Personal Data Collected Invisibly does NOT collect, store, or transmit any personal data, telemetry, or usage statistics. 3.2 Processing Activities All operations run locally on the user's device. The Software processes the following data for the specified purposes: | Data Category | Purpose of Processing | Retention Period | |---------------|----------------------|------------------| | System Configuration Data | Baseline security monitoring and auto-repair | Until user deletes the software or withdraws consent | | System Logs | Incident detection and reporting | 30 days (logs are automatically rotated) | 3.3 Consent The user's consent is obtained at the time of installation. The consent is: - Free, specific, informed, unconditional, and unambiguous - Provided through active opt-in (not pre-ticked) - Withdrawable at any time through the software's dashboard 3.4 Withdrawal of Consent Users may withdraw consent by: - Uninstalling the Software - Or by disabling the Software using the "Disable Invisibly" button in the dashboard 4. Data Storage and Security 4.1 Storage Location All data is stored locally on the user's device at: `C:\ProgramData\Invisibly\` 4.2 Security Safeguards - AES-256-GCM encryption for baseline data - HMAC-SHA256 for tamper detection - TPM binding (optional, falls back to secure HMAC) - Windows ACL hardening on data folders 4.3 Data Retention - System Configuration Data: Retained until user uninstalls - System Logs: Retained for 30 days - Consent Records: Retained as per DPDP Act requirements 4.4 Data Deletion Data is automatically deleted when: - The user uninstalls the Software - The user withdraws consent through the dashboard 5. Data Principal Rights Under the DPDP Act, Data Principals (users) have the following rights: 5.1 Right to Access Users may request access to their personal data by contacting the Grievance Officer. 5.2 Right to Correction and Erasure Users may request correction or deletion of their personal data by: - Uninstalling the Software - Contacting the Grievance Officer 5.3 Right to Grievance Redressal Users may lodge complaints with the Grievance Officer regarding any violation of their rights. 5.4 Right to Withdraw Consent Users may withdraw consent at any time via the dashboard or by uninstalling the Software. 5.5 Right to Nominate Users may nominate a person to exercise their rights on their behalf after death or incapacity. 6.
